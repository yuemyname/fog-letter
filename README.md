# 숨결 · Fog Letter

입김으로 김을 만들고 손끝으로 편지를 쓰는 카메라 거울 웹사이트입니다.

## 실행

```bash
python3 -m http.server 8000 --directory dist
```

http://localhost:8000 에서 실행하세요. 휴대폰 등 다른 기기에서는 HTTPS 배포 주소로 접속해야 카메라와 마이크를 사용할 수 있습니다.

## 기능

- 전면 카메라를 좌우 반전해 거울로 표시
- 마이크 소리 변화로 입김을 추정해 김 서리기
- 검지만 펴서 글씨 쓰기 / 펼친 손바닥을 움직여 넓게 닦기
- 마우스·터치 입력 및 카메라 없는 체험 모드
- 수동 김 서리기·모두 닦기 및 마이크·손 추적 켜기/끄기

카메라 영상과 마이크 소리는 서버로 전송하지 않습니다. 손 추적 라이브러리와 모델은 jsDelivr 및 Google Storage에서, 서체는 Google Fonts에서 불러옵니다. 입김 감지는 주변 소음에도 반응할 수 있습니다. 실제 손 추적과 모바일 호환성은 기기에서 확인해야 합니다.

## 배포

Vercel에서 저장소를 연결하고 Framework Preset을 Other, Output Directory를 dist로 설정합니다. 빌드·설치 명령은 필요하지 않습니다. vercel.json에 설정이 포함되어 있습니다.

## 자연스러운 김 표현

입김은 입 주변에서 시작해 부드럽게 확장하고 위로 올라가는 국소적인 수분 구름으로 표현합니다. 얼굴 감지를 사용할 수 없으면 화면 중앙 아래에서 시작합니다. 수분은 시간이 지나면 서서히 증발하며, 닦은 곳에도 새 입김이 닿으면 다시 응결합니다. 유리의 미세한 물방울은 화면에 고정되어 깜빡이지 않습니다.

손바닥은 방향이 있는 타원형 접촉면과 개별 손가락 경로를 따라 닦습니다. 손 위치를 보간하고, 닦인 가장자리를 부드럽게 처리합니다. 마이크는 지속 시간과 소리 스펙트럼을 이용해 짧은 잡음과 강한 단일 음을 줄입니다. 실제 입김 감지는 마이크 및 주변 소음의 영향을 받습니다.

## 검증

```bash
node tests/condensation.test.mjs
```

수분의 국소 생성·확산·증발, 획 지우기, 재응결, 프레임 속도 차이, 수분 상한, 입김 신호와 손바닥 접촉 모양을 검사합니다. 실제 카메라·마이크·모바일 동작은 기기에서 별도로 확인해야 합니다.
