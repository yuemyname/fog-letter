# 숨결 · Fog Letter

입술 모양으로 김을 만들고 손끝으로 편지를 쓰는 카메라 거울 웹사이트입니다.

사이트: https://fog-letter.vercel.app

## 실행

```bash
python3 -m http.server 8000 --directory dist
```

http://localhost:8000 에서 실행하세요. 다른 기기에서는 카메라를 사용하기 위해 HTTPS 배포 주소로 접속해야 합니다.

## 사용

- 카메라를 허용하고 얼굴과 입이 보이도록 합니다. 마이크 권한은 요청하지 않습니다.
- 입술을 오므려 ‘후—’ 하는 모양을 잠시 유지하면 감지된 입 위치부터 김이 서서히 번집니다.
- 엄지와 검지 끝을 붙여 글씨를 쓰고, 주먹을 쥐고 움직여 넓게 닦습니다. 손바닥을 펴거나 애매한 손 모양이면 아무것도 쓰거나 지우지 않습니다.
- 마우스·터치 입력, 카메라 없는 체험 모드, 수동 김 서리기·전체 닦기도 지원합니다.
- 입모양 감지와 손 추적은 각각 켜거나 끌 수 있습니다.

## 입모양과 김 표현

MediaPipe Face Landmarker의 입술 좌표와 mouthPucker/mouthFunnel 표정 점수로 입술을 오므린 상태를 추정합니다. 단순히 입을 벌리거나 웃거나 하품하는 동작은 가능한 한 제외하고, 짧은 입 움직임은 지속 시간 조건으로 거릅니다. 실제 호흡량을 측정하는 기능은 아니므로 입모양만으로도 반응하며, 조명과 얼굴 방향에 따라 감도가 달라질 수 있습니다.

좌우 반전과 카메라의 화면 채우기 비율을 적용해 입 좌표를 거울 화면으로 옮깁니다. 입을 놓치거나 감지를 끄면 자동 생성이 멈추며, 화면 중앙에 대신 김을 만들지 않습니다. 손 추적을 꺼도 입모양 감지는 계속 동작합니다.

김은 입 근처 작은 영역에서 시작해 확장하고 위로 번지며 서서히 증발합니다. 물방울은 유리 위치에 고정됩니다. 엄지와 검지 끝을 붙이면 두 손끝의 중간 지점에서 굵고 맑게 김을 닦아 글씨를 쓰며, 네 손가락을 접은 주먹은 타원형 접촉면으로 넓게 닦습니다. 관절 각도와 손끝 위치로 두 모드를 구분하고, 주먹은 180ms 유지해야 지우기가 시작됩니다. 모드를 바꾸거나 손을 놓치면 이전 획과 연결하지 않습니다. 두 손끝을 떼면 글씨 쓰기가 멈춥니다. 붙이기와 떼기의 판정 거리를 달리해 떨림을 줄이고 주먹이 글씨로 인식되지 않도록 손끝 위치도 확인합니다. 새 김이 닿으면 닦은 자리에도 다시 응결합니다. 수분은 약 20초마다 37% 수준으로 줄어들고, 30~60초에 걸쳐 김이 눈에 띄게 옅어집니다.

카메라 영상은 서버로 전송하지 않습니다. MediaPipe 라이브러리와 얼굴·손 모델은 jsDelivr 및 Google Storage에서, 서체는 Google Fonts에서 다운로드합니다.

## 테스트

```bash
node tests/condensation.test.mjs
node tests/mouth-gesture.test.mjs
node tests/hand-gesture.test.mjs
```

자동 테스트로 수분 생성·확산·증발, 재응결, 지우기, 프레임 속도 차이, 입모양 분류·지속 시간·얼굴 손실 및 마이크 코드 제거를 확인합니다. 실제 카메라의 모델 인식 정확도와 모바일 동작은 기기에서 별도로 확인해야 합니다.

## 배포

Vercel의 Other 프레임워크, 출력 폴더 dist를 사용합니다. 빌드·설치 명령은 필요하지 않으며 vercel.json에 설정되어 있습니다. main 브랜치 변경 시 연결된 Vercel 프로젝트에 배포됩니다.

## 집기 인식 보정

손가락을 굽혀 집는 동작도 허용합니다. 손끝이 겹칠 때 흔들리는 깊이 추정값 대신 화면상 손끝 간 거리를 손바닥 크기로 정규화해 집기를 판단합니다. 주먹의 손끝이 모인 모습은 별도로 제외합니다. 화면의 두 손끝 표시와 손 인식 상태로 카메라가 손을 찾았는지, 집기를 인식했는지 확인할 수 있습니다. 실제 기기의 모델 정확도는 별도 확인이 필요합니다.
